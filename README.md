## ⚡ Overview
**AetherAI** is a next-generation Agentic Command-Line Interface (CLI) designed to automate, debug, and streamline your entire development workflow natively from your terminal. No complicated GUI, no heavy installations. Just pure neural engine power directly at your fingertips.

Featuring a **"Zero-Install" Payload**, AetherAI runs entirely from a single bundled execution environment and dynamically interacts with your local file system, terminal commands, and project architecture.

## 🚀 Key Features

* 🧠 **Auto-Context Memory**: Mention a file (e.g., `login.html`) and AetherAI will silently locate, read, and inject it into its memory before answering.
* ⚡ **Terminal AI Native (Auto-Execute)**: Tell the AI what you want to build (e.g., `"install react and setup tailwind"`), and it will generate the bash scripts and execute them directly in your terminal.
* 📝 **Silent Auto-Apply Editor**: Ask the AI to fix a bug, and it will silently overwrite your file with the corrected code. Review changes instantly via VS Code Source Control.
* 📂 **Heuristic Project Scanner**: Type `scan .` to allow AetherAI to scan your entire directory structure and provide architectural insights.
* 💀 **Hacker / Recon Mode**: Advanced security analysis and basic reconnaissance methodology directly via terminal prompts.
* 🎨 **Antigravity TUI**: Stunning multi-theme (Tokyo Night, Dracula, Cyberpunk, etc.) Terminal User Interface with side-by-side header layouts and markdown rendering.
