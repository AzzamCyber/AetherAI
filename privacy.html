Privacy Policy

Terakhir diperbarui: Mei 2026

1. Pengumpulan Data

Aether AI berjalan langsung dari terminal (CLI) Anda. Kami tidak mengumpulkan data pribadi, log sistem, atau baris kode sensitif dari lokal Anda. Semua eksekusi AI dan transfer konteks ditangani secara dinamis melalui sesi sementara dan disalurkan ke penyedia layanan AI pihak ketiga (mis. OpenRouter) hanya saat Anda memerintahkannya.

2. Penggunaan API Pihak Ketiga

Untuk memproses input bahasa alami dan kode, Aether AI berinteraksi dengan API eksternal. Segala prompt atau file yang Anda lampirkan dalam perintah (misalnya melalui parameter /scaffold atau file konteks) akan dikirim ke API tersebut. Anda tunduk pada kebijakan privasi dari penyedia API (misalnya Anthropic, OpenAI, Meta) yang mengelola model tersebut.

3. Data Lokal (Memory Cache)

Konfigurasi Anda (seperti preferensi UI, *API key*, dan *long-term memory chat*) hanya disimpan di komputer lokal Anda dalam direktori tersembunyi (contoh: ~/.aetherai_brain.json). Kami tidak pernah mengunggah, mencadangkan, atau menyinkronkan data ini ke server kami.

4. Kebijakan Keamanan Otomatis

Fitur eksekusi otomatis seperti *JARVIS Mode* dan Auto-Fixer /test akan mengeksekusi perintah terminal secara mandiri di mesin Anda. Meski kami berupaya memastikan model memberikan perintah yang aman, **Anda sebagai pengguna bertanggung jawab penuh** atas segala konsekuensi modifikasi sistem lokal Anda yang diakibatkan oleh penggunaan aplikasi ini.
